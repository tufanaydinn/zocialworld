# Art and asset licences

This repository mixes code and assets that are under different terms.

| What | Terms |
|---|---|
| **Code** — everything in this repository unless listed below | MIT, see [LICENSE](../LICENSE). |
| **Original Zocial World artwork and logos** (the hosted deployment's backdrop, logo, icons, social preview image and authored world art) | All rights reserved. Not included in this repository and not covered by the MIT licence. |
| **The ZEC emblem** drawn by the client on boards and screens | The Zcash "Z" mark, used as Zcash ecosystem usage. It stays subject to the Zcash trademark owners' guidelines; the MIT licence grants no rights to it. |
| **Third-party model packs** (Kenney, KayKit) | Each pack keeps its own licence (all current packs are CC0-1.0). The packs, versions, sources and checksums are listed in [LICENSES.md](LICENSES.md) and `asset-registry.json`; verbatim licence texts are in [licenses/](licenses/). |
| **Sample lesson text** (`apps/web/src/content/sample/sampleCurriculum.ts`) | Follows the ZecHub wiki and is under CC BY-SA 4.0, separate from the MIT code licence. |

Notes:

- The model packs are not committed: `npm run assets:fetch` downloads them from their pinned sources and checks
  every file against the registry. Without them the client runs on procedural placeholders.
- The placeholder favicon (`apps/web/public/favicon.svg`) is part of the code tree and is covered by the MIT
  licence.
- Everything else the client draws (terrain, signs, sky, glow sprites and the sample world) is procedural geometry
  or canvas textures generated by MIT-licensed code.
- Contributions of artwork or assets must state their licence; see [CONTRIBUTING.md](../CONTRIBUTING.md).
